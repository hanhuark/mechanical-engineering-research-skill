# Quickstart

Use this page when you want to see whether the plugin is useful before reading the full README.

## Install

Ask Codex:

```text
Install the Codex plugin from https://github.com/hanhuark/mechanical-engineering-research-skill
```

If plugin installation is unavailable, ask for the skill directly:

```text
Install the Codex skill from GitHub repo hanhuark/mechanical-engineering-research-skill, path skills/mechanical-engineering-research.
```

## Try These Prompts

### 1. CFD review

```text
Use the mechanical-engineering-research skill to review this CFD setup for unsupported claims, mesh and wall-treatment issues, boundary-condition concerns, and validation gaps.
```

### 2. Correlation check

```text
Use the mechanical-engineering-research skill to check whether this Nusselt-number correlation is valid for my geometry, Reynolds number, Prandtl number, boundary condition, and property range.
```

### 3. Experiment plan

```text
Use the mechanical-engineering-research skill to design a baseline-first thermal-fluid experiment with sensors, calibration, uncertainty, repeatability, heat-loss correction, and safety checks.
```

### 4. Figure discussion

```text
Use the mechanical-engineering-research skill to rewrite this figure discussion. Explain the dominant physics, compare against expected trends, state uncertainty, and avoid overclaiming.
```

### 5. Proposal aims

```text
Use the mechanical-engineering-research skill to rewrite these proposal aims around the technical barrier, hypothesis, approach, success metrics, risks, alternatives, and expected impact.
```

## What Good Output Should Include

- A direct bottom line.
- Operating assumptions and missing high-impact inputs.
- Thermal-fluid validity checks.
- Evidence separated from inference.
- Safer claim wording when the input overclaims.
- Next calculations, experiments, simulations, or source checks.
