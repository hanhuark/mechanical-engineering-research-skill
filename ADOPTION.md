# Adoption Guide

This guide helps an individual researcher, research group, or instructor use the plugin without treating it as a substitute for scientific judgment, authorship, or independent verification.

## Individual Researcher: First 10 Minutes

1. Install the plugin or one focused skill using the instructions in [README.md](README.md#quick-install).
2. Start with one bounded task you can independently check, such as a literature-review outline, a figure discussion, a DOE plan, or a code-review request.
3. Provide the engineering system, available evidence, operating conditions, desired output, and any source or confidentiality boundary.
4. Inspect the output against the source material, governing physics, units, and intended claim before reusing it.
5. Record a useful failure or improvement as a GitHub issue so the workflow can improve.

## Research Group Or Mentor: A Small Pilot

Use one skill for one recurring activity before rolling it out more broadly:

| Need | Suggested focused skill | Useful pilot output |
| --- | --- | --- |
| Literature-review synthesis | `research-writing-literature` | Mechanism-based evidence map and gap statement |
| Experimental or CFD planning | `research-data-analysis` | Baseline case, hypothesis, and decision-oriented DOE |
| Student draft feedback | `research-mentor-review` | Prioritized revision memo with evidence and next actions |
| Manuscript revision | `reviewer-author-loop` | Reviewer issues, revision plan, verification record, and human-pause items |
| Thermal-fluid interpretation | `thermal-fluid-analysis` | Assumption list, governing mechanism, and validity limits |

Keep unpublished manuscripts, confidential proposals, student records, sponsor-restricted data, and credentials out of public issue reports. The responsible author, instructor, and investigator remain accountable for all scientific and professional decisions.

## Course Companion

For a project-based AI/ML curriculum that teaches corresponding engineering habits, see [Machine Learning for Engineers](https://github.com/hanhuark/machine-learning-for-engineers). The curriculum is useful for learners and instructors; this plugin is useful for applying structured research workflows in active work.

## Feedback That Helps

The most useful feedback identifies the task context, expected outcome, observed problem, and a reusable improvement. Please avoid uploading restricted material. A minimized, synthetic, or redacted example is usually enough to report an issue.

## Citation

GitHub can export the preferred citation from [CITATION.cff](CITATION.cff). Until a versioned archival release has a DOI, cite the repository URL together with the specific release tag or commit used.
