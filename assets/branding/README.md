# Branding Assets

`mechanical-engineering-research-skill-social-preview.png` is a GitHub social-preview candidate for this repository. It is a deterministic communications graphic built from simple, illustrative thermal-flow, evidence, and workflow motifs. It does not represent measured apparatus, data, or a scientific result.

Regenerate the PNG on Windows with:

```powershell
powershell -ExecutionPolicy Bypass -File .\assets\branding\create_social_preview.ps1
```

Before publishing, inspect the output at GitHub's social-preview crop and set it through **Repository Settings -> General -> Social preview**. The asset is not activated by placing it in the repository.
