# Build Research Schematic

Use `research-schematic-design` with `mechanical-engineering-research` when the figure involves thermal-fluid physics, experimental hardware, models, AI/ML workflows, or scientific evidence boundaries.

Workflow:

1. State the figure's single scientific job and audience.
2. Complete the schematic brief: evidence class, objects, paths, exact labels and units, hierarchy, style, and exclusions.
3. Choose native-vector, hybrid concept-to-vector, or controlled image-edit production.
4. Keep all final labels, arrows, dimensions, symbols, and legends editable and deterministic.
5. Render at final use size and run the scientific visual QA.
6. Preserve a compact provenance note with sources, conceptual elements, editable source path, and verification status.

Expected output:

- completed schematic brief
- recommended production lane and rationale
- editable-source plan or created source artifact
- image-generation prompt only when a concept frame is justified
- final-size QA checklist and unresolved author decisions
