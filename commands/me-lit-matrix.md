# Thermal-Fluid Literature Matrix

Use `mechanical-engineering-research` to transform a pile of papers into a mechanism-based literature matrix.

Workflow:

1. Define the review question and the decision the review must support.
2. Group papers by mechanism, geometry, regime, method, working fluid, diagnostic, or performance metric.
3. Extract operating ranges, assumptions, measured or simulated quantities, correlations, and uncertainty.
4. Record each paper's contribution, limitation, and transferability to the user's system.
5. Identify benchmark tables, comparison plots, mechanism maps, and unresolved gaps.
6. Avoid one-paper-one-paragraph summaries unless the paper is foundational.

Expected output:

- literature matrix
- mechanism map
- benchmark table or figure plan
- critical gap synthesis
- search strategy for missing source families
