# Thermal-Fluid Experiment Plan

Use `mechanical-engineering-research` to design or review a thermal-fluid experiment before data collection.

Workflow:

1. Define the hypothesis, baseline case, dependent variables, independent variables, and controlled conditions.
2. Identify the facility, flow path, heating or cooling path, working fluid, geometry, and operating envelope.
3. Specify sensors, calibration, sampling rate, synchronization, uncertainty, repeatability, and data reduction.
4. Plan flow development, heat-loss correction, steady-state or transient criteria, degassing, startup, shutdown, and safety.
5. Choose a small case matrix that tests the mechanism before broad sweeps.
6. Define pass/fail checks before the experiment begins.

Expected output:

- baseline case definition
- instrumentation and calibration plan
- uncertainty and repeatability plan
- hypothesis-driven DOE
- safety and operating-limit checklist
- data products and plots
