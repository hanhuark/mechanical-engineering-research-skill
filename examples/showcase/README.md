# Showcase Examples

These examples are synthetic, public-safe artifacts that demonstrate the intended behavior of the `mechanical-engineering-research` skill and Thermal-Fluid Research Workflow Plugin.

They are not experimental results, citations, or performance claims. They are compact examples of how the plugin should steer an AI agent toward thermal-fluid rigor.

| Example | Demonstrates |
|---|---|
| [`cfd-review-memo.md`](cfd-review-memo.md) | CFD claim review, mesh and wall-treatment critique, and safer claim wording. |
| [`heat-exchanger-design-matrix.md`](heat-exchanger-design-matrix.md) | Mechanism-based design comparison rather than single-metric ranking. |
| [`boiling-literature-matrix.md`](boiling-literature-matrix.md) | Literature synthesis by mechanism, method, validity range, and gap. |
| [`proposal-aims-rewrite.md`](proposal-aims-rewrite.md) | Proposal aims rewritten around barrier, hypothesis, metrics, and risk. |
| [`figure-discussion-before-after.md`](figure-discussion-before-after.md) | Results discussion rewritten from trend reporting to physical explanation. |
